Insider-Shield

Only used when no enterprise-managed policy supplies an employee identity. Attached to this device's heartbeats/DLP events so the SOC dashboard can attribute this session to a specific employee (needed for the per-employee offboard/revoke action).

Required for this device's WebSocket connection to be accepted by the server at all. Only used when no enterprise-managed policy supplies one. Paste a per-device token from the dashboard's Agent Provisioning page here, or the shared ORG_ACCESS_KEY.

Defaults to ws://localhost:3000/api/ws if left blank. Set this to your deployed SOC dashboard's wss://.../api/ws URL for this device to report to a real deployment instead of a local dev server. Only used when no enterprise-managed policy supplies one.
